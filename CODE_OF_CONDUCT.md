# Code of Conduct

## Our standard

Contributors should keep discussion respectful, direct, and useful. This project is intended to help founders and operators improve onboarding systems, so feedback should focus on clear operating value, correctness, and maintainability.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Publishing private customer data or confidential company data.
- Posting secrets, credentials, API keys, or personal data.
- Repeated off-topic or disruptive comments.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors who violate this code of conduct.
