# Security

## Supported versions

This public template supports the current `main` branch.

## Reporting a vulnerability

Open a GitHub issue if you find a security concern in the template code. Do not include secrets, customer data, credentials, or private company information in the issue.

## Data safety

This repository is designed for offline CSV and YAML workflows. The sample data is synthetic. If you fork this repo for your company, do not include proprietary, confidential, customer-identifiable, or sensitive company data in a public repository.

Use synthetic, anonymized, or public example data only. Remove company names, customer identifiers, internal metrics, credentials, tokens, and operationally sensitive details before sharing examples.

The base workflow does not require API keys, paid APIs, LLMs, or external services.
