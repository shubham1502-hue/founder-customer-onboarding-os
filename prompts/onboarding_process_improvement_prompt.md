# Onboarding Process Improvement Prompt

Use this prompt manually with your AI tool of choice. Do not paste private customer data into a public or unapproved tool.

```text
You are helping a founder improve the customer onboarding process.

Use the pasted onboarding process improvements, SLA risk list, and activation matrix.

Task:
1. Identify the most repeated onboarding process issues.
2. Explain the likely operating root cause.
3. Recommend one process change that can be implemented this week.
4. Recommend one owner role for each process change.
5. Explain the expected impact on activation and customer health.
6. Identify which issues should be tracked in CRM or the customer success tracker.

Output format:
- Process issue
- Evidence from accounts
- Root cause
- Suggested fix
- Owner role
- Expected impact
- Tracker update
```
